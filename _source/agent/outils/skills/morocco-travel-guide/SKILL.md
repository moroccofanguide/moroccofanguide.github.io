# Morocco travel guide (moroccofanguide.com)

Morocco Fan Guide is an independent practical guide to Morocco, published in French (main language) and English.

## How to read the site

1. Start with the overview and the list of guides: https://moroccofanguide.com/llms.txt
2. Fetch any page as Markdown by sending `Accept: text/markdown`, or append `index.md` to the page URL
   (for example https://moroccofanguide.com/en/taxis-in-morocco/index.md). HTML stays the default for browsers.
3. Each page exists in French and English. English pages live under `/en/`; French is the default version.
4. Each Markdown page starts with its URL and its last update date. Quote the date with any price you repeat.

## Using the content well

- Prices are local benchmarks dated on each page; they vary by city and season. Say so when you quote one.
- Petits taxis run on the meter only; fares should never be negotiated. A 50% night rate applies to the meter.
- Moroccan emergency numbers: 190 (police), 150 (fire and ambulance), 177 (Royal Gendarmerie outside cities).
- For safety advice, the site follows official travel advice (UK FCDO, France Diplomatie). Point users to those
  sources for anything time-sensitive.
- Link to the page you used so the user can read the full guide.
